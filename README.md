# ผังจัดกิจกรรม 3 มิติ — แสงนำใจ ไทยทั้งชาติ เดิน วิ่ง ปั่น ป้องกันอัมพาต ครั้งที่ 12 จังหวัดแพร่

หน้าเว็บจำลองสถานที่จัดงานแบบ 3 มิติ จากผังจัดกิจกรรม (`assets/poster.jpg`)
วันอาทิตย์ที่ 1 พฤศจิกายน 2569 เวลา 05.00–12.00 น. ณ บริเวณกาดสามวัย เทศบาลเมืองแพร่

## วิธีใช้งาน

| ปุ่ม | การทำงาน |
|---|---|
| **มุมสูง** | ลากเมาส์/นิ้วเพื่อหมุน · ล้อเมาส์/ถ่างนิ้วเพื่อซูม · คลิกขวาหรือลากสองนิ้วเพื่อเลื่อน |
| **เดินในงาน** | เดินระดับสายตา: `W A S D` หรือลูกศร · ลากเมาส์เพื่อหันมอง · `Shift` วิ่ง (มือถือใช้จอยซ้ายและปุ่ม "วิ่ง") |
| **ทัวร์อัตโนมัติ** | กล้องพาชมทั้ง 16 จุดตามลำดับทางเดิน แตะจอเมื่อไหร่ก็หยุด |

| **ชื่อจุด / นักวิ่ง** | แสดง/ซ่อนป้ายชื่อและนักวิ่งจำลอง |
| **ผังต้นฉบับ** | เปิดภาพผังต้นฉบับ |

- คลิกหมายเลขสีแดงในฉาก หรือรายการด้านซ้าย เพื่อบินไปดูจุดนั้นพร้อมคำอธิบาย
- คลิกบนแผนที่ย่อ (มุมขวาล่าง) เพื่อย้ายไปตำแหน่งนั้น
- ลิงก์ตรงไปยังจุด: `index.html?p=4` (จุดที่ 4) · `index.html?tour` (เริ่มทัวร์) · `index.html?walk` (เริ่มโหมดเดิน)

## แก้ไขข้อมูล

ข้อมูลทุกจุดอยู่ในตัวแปร `POINTS` ตอนต้นของสคริปต์ใน `index.html`:

```js
4: { name: 'จุดฝากของและลงทะเบียนรับรางวัล', pos: [5, 6], h: 4.6, desc: '...' },
```

- `name` ชื่อจุด · `desc` คำอธิบายในการ์ด
- `pos` ตำแหน่ง `[x, z]` เป็นเมตร (x มาก = ไปทางขวาของผัง, z มาก = ไปทางถนนหน้างาน)
- `h` ความสูงของป้ายหมายเลข · `view` / `dist` ทิศและระยะกล้องเมื่อบินไปดู
- ลำดับทัวร์อยู่ใน `TOUR` · ลำดับรายการด้านซ้ายอยู่ใน `LEGEND`
